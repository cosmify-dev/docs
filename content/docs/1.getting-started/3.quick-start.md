# Quick Start

This guide will help you deploy your first application on Cosmify. We'll walk through creating an organization, adding a server, and deploying a simple web application.

## Prerequisites

Before you begin, make sure you have:

- ✅ Cosmify installed and running (see [Installation](/docs/getting-started/installation))
- ✅ A registered account on your Cosmify instance
- ✅ A server with Docker installed (can be the same server running Cosmify)
- ✅ SSH access to your target server

## Step 1: Create an Organization

Organizations help you organize projects and manage team access.

1. Log in to your Cosmify dashboard
2. Click **"Create Organization"** on the home page
3. Enter your organization details:
   - **Name**: My First Organization
   - **Description**: Optional description
4. Click **"Create"**

## Step 2: Add a Server

Servers are the compute resources where your applications will run.

1. Navigate to **Servers** in the sidebar
2. Click **"Add Server"**
3. Fill in the server details:
   - **Name**: Production Server
   - **Host**: Your server's IP address or hostname
   - **Port**: 22 (default SSH port)
   - **Username**: Your SSH username (e.g., `root` or `ubuntu`)
   - **SSH Key**: Select or add your SSH private key
4. Click **"Test Connection"** to verify SSH access
5. Click **"Add Server"**

Cosmify will now connect to your server and verify Docker is installed.

## Step 3: Create a Project

Projects group related applications and services together.

1. Click **"Projects"** in the sidebar
2. Click **"Create Project"**
3. Enter project details:
   - **Name**: My Web App
   - **Organization**: Select your organization
   - **Description**: My first application on Cosmify
4. Click **"Create"**

## Step 4: Deploy a Container

Let's deploy a simple Nginx web server as your first application.

1. Open your project
2. Click **"Deploy Container"**
3. Configure the container:
   - **Name**: web-server
   - **Image**: nginx:latest
   - **Server**: Select your server
   - **Port Mapping**: Add port mapping
     - **Container Port**: 80
     - **Host Port**: 8080
4. Click **"Deploy"**

Cosmify will now:
- Pull the Nginx image on your server
- Create and start the container
- Configure port mapping

## Step 5: Verify Deployment

1. Once deployed, you'll see the container status change to **"Running"**
2. Navigate to **Containers** to see your deployed containers
3. Click on your container to view details, logs, and metrics
4. Open your browser and visit: `http://your-server-ip:8080`

You should see the Nginx welcome page! 🎉

## Step 6: Configure Environment Variables (Optional)

Many applications require environment variables for configuration.

1. Open your container details
2. Click **"Environment Variables"**
3. Add variables:
   - **Key**: `MY_VARIABLE`
   - **Value**: `my-value`
4. Click **"Save"**
5. Restart the container for changes to take effect

## Step 7: Manage Your Container

From the container details page, you can:

- **View Logs**: Real-time container logs
- **Restart**: Restart the container
- **Stop**: Stop the container
- **Remove**: Delete the container
- **Update**: Update container configuration

## Common Deployment Scenarios

### Deploy a Node.js Application

```yaml
Name: my-node-app
Image: node:18-alpine
Working Directory: /app
Command: node server.js
Port Mapping:
  - Container: 3000
  - Host: 3000
Environment Variables:
  - NODE_ENV=production
  - PORT=3000
```

### Deploy a Database (PostgreSQL)

```yaml
Name: postgres-db
Image: postgres:15
Port Mapping:
  - Container: 5432
  - Host: 5432
Environment Variables:
  - POSTGRES_USER=myapp
  - POSTGRES_PASSWORD=secure_password
  - POSTGRES_DB=myapp_db
Volumes:
  - /var/lib/postgresql/data
```

### Deploy a Custom Application

```yaml
Name: my-custom-app
Image: myregistry.com/my-app:latest
Port Mapping:
  - Container: 8000
  - Host: 8000
Environment Variables:
  - DATABASE_URL=postgresql://user:pass@db:5432/mydb
  - REDIS_URL=redis://redis:6379
Network: my-app-network
```

Cosmify will soon support deploying multi-container applications using Docker Compose files:

```yaml
      - NODE_ENV=production
    depends_on:
      - db

    image: postgres:15
    environment:
      - POSTGRES_PASSWORD=secret
```

## Troubleshooting

### Container Won't Start

- Check the container logs for error messages
- Verify the Docker image exists and can be pulled
- Ensure port mappings don't conflict with existing services
- Check environment variables are correctly set

### Can't Access Application

- Verify the container is running
- Check port mappings are correct
- Ensure firewall allows traffic on the mapped port
- Confirm the application is listening on `0.0.0.0` not `localhost`

### SSH Connection Failed

- Verify SSH credentials are correct
- Check the server is accessible from Cosmify
- Ensure SSH key has proper permissions (600)
- Verify Docker is installed on the target server
